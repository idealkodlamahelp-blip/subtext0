## 🇬🇧 ENGLISH (DEMO & USER GUIDE)

### 📌 Overview
Subtext is a modern web application designed to reverse-search books based on single quotes, sentences, or fragments. Even if a reader forgets the author or title, typing a remembered line pulls up matching records from both local curated archives and worldwide sources, complete with confidence scoring.

### 🚀 Key Features
1. **🔍 Quote & Sentence Search:**
   - Searches local repository and worldwide library indices.
   - Automatic deduplication prevents duplicate book entries.
   - Displays match percentage, source evidence, and highlighted phrases.
2. **🤖 AI Verification & Anti-Troll Defense:**
   - Integrated with Google Gemini to evaluate user-submitted books.
   - Plausibility checks block troll or spam entries before publication.
3. **📄 PDF Attachment & Lightweight Sentence Indexing:**
   - Books require a verifiable PDF link or sample.
   - AI extracts sentence representations with minimal server memory footprint.
   - Submissions require owner approval before going live.
4. **🛡️ Permanent Email Ban & Live Appeals Screen:**
   - Replaced fragile IP blocking with authoritative **Email Ban** tracking.
   - Banned accounts are presented with a fullscreen restriction screen.
   - Built-in appeal submission form; auto-polling (every 3 seconds) restores access immediately upon admin unban.
5. **👑 Owner-Only Admin Dashboard:**
   - Dedicated access for the verified owner: **`rsulovbabk3@gmail.com`**.
   - Accessible via standard Google Sign-In.
   - Comprehensive user registration logs with precise timestamps.
   - Pending book approval queue and banned email management.
6. **🎵 Music Mood Analysis:**
   - Analyzes audio files in real-time in the browser (tempo, energy, brightness).
   - Maps musical mood to literary genres and classic novels.
7. **💳 Reader Card & 10 AZN Incentive Rewards:**
   - Generates personalized reader cards and archetype personas.
   - 150 verified five-star ratings grant a 10 AZN reward.
8. **📱 Seamless Mobile Experience:**
   - Solves mobile popup redirects with in-place direct email authentication.

## 🛠️ Texnoloji Stack / Tech Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend / Serverless:** Vercel Serverless Functions (`/api/search`, `/api/book-suggestion`, `/api/email-code`)
- **AI Engine:** Google Gemini API (`gemini-2.5-flash`)
- **Auth:** Google Identity Services (OAuth 2.0) & Direct Email Verification
- **Storage:** Serverless State Engine (`/tmp/` + `globalThis` persistent fallback) & IndexedDB / localStorage
- **Documentation:** Automated PDF generation via Chromium Headless Engine
